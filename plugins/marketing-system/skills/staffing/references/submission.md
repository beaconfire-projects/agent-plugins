# Submissions

Submissions have one set of tools, shared with the Marketing skill: `marketing_get_workspace_submission`, `marketing_create_submission`, `marketing_update_workspace_submission`, `marketing_reject_submission` and `marketing_reopen_submission` (the older staffing-only tools `marketing_get_submission`, `marketing_update_submission` and `marketing_submit_candidate_to_position` no longer exist). Follow `skills/marketing/references/submission.md` for every submission request: reading, creating (a candidate can have several submissions on one position), editing the details, Level and Lead (with the submission's own `version`), rejecting with the rejecting party (`Candidate` or `Company`) and a reason, and reopening.

A **submission** is a candidate on one position of one vendor (`SUB-nnnnnn`). Pay rate, start availability, relocation, travel, interview availability, same-client history and the C2C employer belong to the submission, not the person; LinkedIn, Facebook, phone and laptop preference are the person's (`marketing_update_candidate`, see `references/candidate.md`).

Find a submission code in `marketing_get_candidate_detail` (`submissions`) or take the `SUB-…` code from the user, then `marketing_get_workspace_submission`. To submit a candidate to a position, resolve both with the selectors, run `marketing_check_submission`, then `marketing_create_submission`. Offered is derived from Offers and is never set by hand.
